1. 歧义默认值：以下词在中文有非制造歧义，**一律按制造含义翻译**：
   - Wafer = 晶圆（半导体制造，不译"薄饼"）
   - Die = 裸晶 / 芯片 die（半导体，不译"死亡"）
   - Foundry = 晶圆代工厂（半导体语境，不译"铸造厂"）
   - FAB = 晶圆厂（半导体制造）
   - Node = 制程节点（半导体语境）
   - Packaging = 封装（半导体，不译"包装"）
   - Chip = 芯片（不译"薯片"）
   - Memory = 内存 / 存储（不译"记忆"）
   - Cell = 电池电芯 / 存储单元（按语境）
   - SMT = 表面贴装（Surface Mount Technology）
   - Assembly = 组装 / 装配（整机制造语境）
   - Tooling = 模具与工装（不译"工具化"）
   - Shop floor = 车间现场 / 产线（不译"商店地板"）
   - Plant = 工厂 / 产线（不译"植物"）
   - Line = 产线（制造语境）
   - Ramp / Ramp-up = 产能爬坡（不译"斜坡"）
   - Yield = 良率（半导体/制造，不译"收益"）
   - Throughput = 吞吐量 / 节拍产出（制造语境）
   - Footprint = 制造布局 / 工厂足迹（不译"脚印"）
   - Headcount = 员工人数（不译"人数统计"）
   - Downtime = 停机时间（不译"停工期"）
   - Rack = 机架 / 机柜（服务器语境，不译"架子"）
   - Liquid cooling = 液冷（不译"液体冷却"）
